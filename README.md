# Calculadora de Áreas

Aplicação de console em Java que calcula a área de um quadrado, retângulo ou círculo. O projeto separa a classe de cálculo geometria.Calculadora do ponto de entrada principal e usa Scanner para receber os valores.

## Requisitos

- JDK 8 ou superior

## Como executar

Na pasta do projeto, compile os arquivos para a pasta out e execute a classe principal:

javac -d out Calculadora.java principal.java
java -cp out principal

Escolha uma opção no menu e informe as medidas solicitadas. Os resultados são exibidos com duas casas decimais.
